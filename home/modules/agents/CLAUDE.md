# AGENTS.md

## 概要
このファイルは LLM AGENT 向けのベースルールを定義しています。

## AGENT としてのルール
- 常に日本語で解答せよ
- コードの品質と保守性を重視せよ
- 変更を行う前に、既存のコードスタイルとパターンを理解せよ
- 自律的に tool を活用して、実装を進めること

## コーディング哲学
- **Infrastructure as Code**: すべての設定は宣言的に管理する
- **明示的であれ**: 暗黙的な動作よりも明示的な設定を優先する
- **再現可能性**: 環境構築は完全に再現可能であるべき
- **最小権限の原則**: 必要最小限の権限で動作させる

## 実行マシンの理解
- このマシンは `nix-darwin` + `home-manager` で管理されている
- システムレベルの設定: `nix-darwin`
- ユーザーレベルの設定: `home-manager`
- GUI アプリケーション: `nix-homebrew` (Homebrew Casks)

## 変更を行う際の注意点
- 破壊的な変更を行う前にユーザーの確認を取れ
- バックアップの存在を確認してから大きな変更を適用せよ

## 開発環境
- エディタ: VSCode
- シェル: Zsh
- バージョン管理: Git + 1Password SSH Agent
- パッケージマネージャー: Nix, pnpm

## セキュリティ
- SSH キーは 1Password で管理
- Git の署名も 1Password 経由
- 機密情報はコードに含めない
